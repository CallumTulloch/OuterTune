# コンテンツの由来と `isLocal`

`isLocal` の意味はEntityごとに異なるため、どのEntityの値かを区別して扱う。

| Entity | `isLocal = true` の意味 | オンライン曲のダウンロード |
| --- | --- | --- |
| `SongEntity` | 端末のフォルダから検出した曲 | `isLocal = false` のまま。`dateDownload` と `localPath` で管理する |
| `AlbumEntity` | フォルダ曲のメタデータから生成したアルバム | ダウンロードしてもローカル扱いにはしない |
| `ArtistEntity` | フォルダ曲のメタデータから生成したアーティスト | ダウンロードしてもローカル扱いにはしない |
| `PlaylistEntity` | YouTube Music側と同期せず、OuterTune内だけで管理する再生リスト | 収録曲の由来とは無関係 |

ライブラリ画面の「アルバム」「アーティスト」「再生リスト」に表示する第2条件は、
次の意味とする。

- **ライブラリ**: 対象カテゴリの従来のライブラリ範囲。フォルダ曲を含む。
- **ダウンロード済み**: ダウンロードしたオンライン曲を1曲以上含むもの。
- **フォルダ**: `SongEntity.isLocal = true` の曲を1曲以上含むもの。
- 第2条件をすべてOFFにした状態は、由来で絞り込まず全件を表示する。
- 第2条件を1つ以上ONにした場合は、ONにした条件同士をORで評価する。
- 再生リストの **フォルダ** 判定は `playlist_song_map -> song.isLocal` を使い、
  `PlaylistEntity.isLocal` は使わない。該当する混在再生リストを開いた後は、由来を問わず全収録曲を表示する。

「曲」画面と、ライブラリ画面内の「曲」表示では、次のように曲単位で判定する。

- **ライブラリ**: オンライン曲 (`isLocal = false`) かつ `inLibrary` が設定されている曲。
- **DL済み**: オンライン曲 (`isLocal = false`) かつ `dateDownload` が設定されている曲。
- **フォルダ**: フォルダ曲 (`isLocal = true`) かつ `inLibrary` が設定されている曲。

独立した「曲」画面では、**ライブラリ**、**DL済み**、**フォルダ**をそれぞれ独立して選択できる。
曲の条件をすべてOFFにした状態はこの3条件で絞り込まず、1つ以上ONにした場合はONにした条件同士を
ORで評価する。

**いいね済み** はこの3条件とは別の条件として扱い、その結果とANDで組み合わせる。
**いいね済み OFF** は「いいねしていない曲」に絞る意味ではなく、いいね状態で絞り込まない。

| いいね済み | 曲の条件 | 表示対象 |
| --- | --- | --- |
| OFF | すべてOFF | 全曲 |
| OFF | ライブラリON | オンラインのライブラリ曲 |
| ON | すべてOFF | 全曲のうち、いいね済みの曲 |
| ON | ライブラリON | オンラインのライブラリ曲のうち、いいね済みの曲 |

`PlaylistEntity.isLocal` は再生リストの同期・所有形態を表す既存名称であり、
収録曲が端末ファイルかどうかを表す値ではない。

## 「端末内メディアを有効にする」のON／OFF

- **OFF**: 実行中のローカルスキャンを中止して完了を待ち、`SongEntity.isLocal = true` の曲を
  DBから物理削除する。フォルダナビとフォルダ由来の表示は設定反映時点で隠す。
- フォルダ曲の削除により、外部キーが設定されている再生リスト内の曲、再生履歴イベント、
  再生キュー、Album／Artist／Genreとの対応表も連動して削除される。
- 削除前に実行中・待機中のスキャンと再生キュー保存を停止して完了を待つ。OFFの間は
  ローカルスキャナーを停止状態に保ち、遅延処理によるフォルダ曲の再登録を防ぐ。
- 外部キーを持たない再生回数、歌詞、フォーマット情報は、曲を削除する前に
  `song.isLocal = true` の曲IDだけを使って明示的に削除する。
- ローカルのAlbum／Artist／Genre Entityも削除する。再生リストEntity自体は曲の由来を
  表さないため残し、フォルダ曲に対応する行だけを再生リストから削除する。
- 端末上の音楽ファイル、スキャン対象／除外フォルダ、オンライン曲とそのいいね・履歴・歌詞・
  ダウンロード／フォーマット情報は削除しない。ダウンロード済みオンライン曲も
  `SongEntity.isLocal = false` なので削除対象外となる。
- **ON**: フォルダナビを復帰し、ストレージ権限の確認後、保存済みのスキャン対象フォルダから
  新規に取り込む。OFF時に削除したフォルダ曲のいいね・履歴等は復元しない。
- OFF処理が途中で中断された場合は、次回起動時にも同じ削除処理を再実行する。
- 混在キューはオンライン曲だけを残す。削除でシャッフル順に欠番が生じた場合は、安全な
  通常順へ戻して読み込み、範囲外の再生位置は残存曲の範囲内へ補正する。

## フォルダ曲のArtist／Album Artist

- 曲の `Artist` とアルバムの `Album Artist` は別のクレジットとして保存する。
  `Album Artist` を曲のArtist一覧・曲数集計へ混ぜない。
- 同じ表示名でも、フォルダ由来のArtist (`isLocal = true`) とオンラインArtist
  (`isLocal = false`) は別Entityとして解決する。
- 同名アルバムの照合は、MusicBrainz Album ID、Album Artist、同一フォルダ、年の順に
  信頼度を下げて判断する。既知のMusicBrainz Album IDまたはAlbum Artistが異なるものは
  統合しない。年は補助情報であり、同じフォルダ内の年表記の揺れだけでは分割しない。
- 再スキャン時は同一ファイルパスを最優先する。パスが変わった場合のメタデータ照合では
  Album Artistも比較し、候補が同点なら既存のどれかへ推測で上書きせず新規曲として扱う。
- TagLib／FFmpegスキャンではMusicBrainz Album IDを利用できる。MediaStoreスキャンでは
  Album Artist列がない、または空の場合のみ、アルバムとフォルダの組み合わせごとに1回だけ
  Android標準のメタデータ取得で補完する。
